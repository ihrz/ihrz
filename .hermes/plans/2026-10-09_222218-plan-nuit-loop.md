# Plan : fiabiliser PLAN.md (directive de boucle de nuit GO NUIT)

## Goal

Rendre `PLAN.md` (racine du repo) une directive de nuit complète, testée et
auto-suffisante : un modèle sans contexte qui reçoit le bloc GO NUIT doit
pouvoir tourner en boucle (re-plan → code → vérif → push) sans deviner.

## Current context / assumptions

- Fichier existant : `/home/kisakay/Documents/Code/GitLab/ihrz/PLAN.md`
  (40 lignes), déjà commité (`381d56d4a`) et poussé sur `rust-recode`,
  workdir propre.
- Le contenu actuel couvre : bloc GO NUIT en 5 étapes + règles dures +
  contexte persistant. Vérifié lisible et conforme à la demande.
- Gaps connus (à combler ci-dessous) : pas de template de prompt worker,
  pas de conduite en cas de trio rouge après retour d'agents, pas de
  garde-fou d'arrêt, workdir des commandes cargo implicite, pas de
  procédure de test du "renvoi à froid".
- Ne rien supposer sur les outils du modèle cible au-delà de : lecture de
  fichiers, `terminal`, `delegate_task`, `patch`/`write_file`, `git`.

## Architecture / proposed approach

Ne pas réécrire PLAN.md d'un bloc : appliquer 4 patchs ciblés (template
worker, conduite trio rouge, garde-fous, auto-test), puis valider par une
checklist de relecture mécanique (chaque exigence de la demande mappe à
une ligne du fichier). Un seul commit à la fin si tout est vert.

## Risks, tradeoffs, and open questions

- Risque : le modèle cible n'a pas `delegate_task` (hors Hermes). Mitigation
  assumée : la demande source l'exige déjà au point 2 ; ne pas ajouter de
  fallback qui diluerait la directive. Question ouverte : faut-il une
  variante "sans sous-agents" (batch séquentiel) ? Proposé : non (YAGNI —
  le loop actuel repose dessus, tous les workers le supportent).
- Risque : boucle infinie réelle (coût). Mitigation : garde-fou 3c (3
  tours sans vert → stop). Tradeoff accepté : un faux stop est moins grave
  qu'une dérive nocturne.
- Risque : les numéros de ligne Task 2-4 dérivent si PLAN.md change entre
  la lecture et le patch. Mitigation : matcher sur le texte exact fourni
  (outil `patch` flou), jamais sur des numéros.
- Question ouverte : faut-il versionner les rapports d'audit ailleurs que
  `~/.hermes/cache` (éphémère, 24h) ? Hors scope (YAGNI) — noté ici pour
  une prochaine itération : copier les listes NEW-ROADMAP-ITEMS dans
  `ops/rust-migration/` avant purge.
